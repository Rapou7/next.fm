# next.fm roadmap

## Explicitly deferred
- [ ] Genre Tops: define tag attribution, enrich artists, and handle unknown/multiple genres.
- [ ] Time-based Tops: evaluate coverage and ranking rules using the range-aware estimated minutes in Summary.

## Next iterations
- [ ] Add opt-in user profiles with visibility controls and compare track, artist, and album Tops between two profiles over the same date range.
- [ ] Evaluate Deezer, iTunes and MusicBrainz fallbacks for unresolved recordings.
- [ ] Validate an Actions-built IPA on iPhone 15 / LiveContainer / iOS 27.0.1.
- [ ] Last.fm Stats Web JSON import/export with source attribution where code is adapted.
- [ ] Full history reconciliation for edited/deleted and late-submitted scrobbles.
- [ ] Preserve multiplicity for identical events sharing a timestamp across pagination boundaries.
- [ ] Dedicated disk-backed artwork cache and artist imagery enrichment.
- [ ] Calendar heatmap, discovery, milestones, and historical ranking movement.
- [ ] Profile large histories (100k–1m events); move queries/aggregation into SQLite if needed.
- [ ] Accessibility and Dynamic Type device audit, especially floating range controls.
- [ ] Multi-account switcher, cache management, and user-initiated data deletion.
- [ ] Widgets and shareable recaps (after checking LiveContainer extension support).
- [ ] Optional authenticated Last.fm actions and scrobbling.
- [ ] Evaluate xtool/WSL after the Xcode build and device launch are verified.
